# Наша маленькая история ❤️

Интерактивная игра-сайт для Камиллы. Это чистый HTML/CSS/JS: без сборки, без зависимостей и без backend.

## Как добавить фото и место первых объятий (уровень 2)

1. Положи фото в `assets/photos/first-hug.jpg`. Лучше заранее уменьшить его примерно до 1200 px по длинной стороне.
2. Открой `js/config.js` и при желании заполни поля `placeName`, `address`, `lat` и `lng`.
   Если указать координаты, в уровне появится настоящая карта (OpenStreetMap) с отметкой и ссылка «Открыть в Картах».

Пока фото или координаты не добавлены, уровень всё равно работает: соответствующие блоки просто не показываются.

## Локальный запуск

```
python -m http.server 5173
```
Потом открой http://localhost:5173

## Публикация на Vercel

Импортируй папку как новый проект: Framework Preset = **Other**, Build Command и Output Directory оставь пустыми.
Можно и через CLI: `npx vercel --prod`.

## Структура

- `index.html` — каркас страницы
- `css/styles.css` — оформление
- `js/app.js` — экраны, квесты, прогресс (localStorage)
- `js/sound.js` — звуки, которые синтезируются в браузере (без аудиофайлов)
- `js/config.js` — личные настройки (фото и место)
